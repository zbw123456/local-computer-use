# 安全设计与边界

## 已实现的机制

- 服务只绑定 `127.0.0.1`，不提供修改监听地址的参数。
- 每次启动生成新的随机连接口令，通过 URL fragment 交给本机页面，随后从地址栏移除。浏览器仅在当前会话存储该口令，API 请求使用 Authorization header。
- API 校验 Host、Origin、Fetch Metadata 和口令，不开放跨域访问；静态文件采用固定路由，不能用路径遍历读取 `.env`。
- CSP 禁止外部脚本和页面嵌入；界面使用 `textContent` 展示模型与窗口文本，不将其当作 HTML 执行。
- 每次任务只使用明确选择的目标窗口；每个动作经过参数检查和独立批准。模型不能申请系统权限或批准自己的操作。
- 原生层再次检查目标、焦点、位置、控件状态；一次观察最多执行一个动作，旧批准和旧观察不能复用。
- API 端点必须使用 HTTPS，本机回环地址例外。拒绝 HTTP 重定向，避免 Authorization 意外转发到其他地址。
- 默认不保存截图、控件树、任务正文、输入文本和模型输出。审计文件只记录时间、事件类型、步数、动作类型和运行 ID。

## 哪些数据会离开电脑

非演示模式会向 `OPENAI_BASE_URL` 指向的服务发送：用户任务、窗口截图、窗口标题、辅助功能控件文本、操作及结果历史。API Key 只发到该配置端点。更改端点意味着改变数据接收方。

程序没有分析统计、广告、远程配置或自动更新服务。浏览器静态资源全部由本机提供。

`store:false` 控制 Responses API 的响应存储方式，不能替代供应商的数据保留政策。截图包含窗口中的实际像素；隐藏 SecureTextField 的 AX 值不是截图脱敏。

## 不能保证的事项

- 这不是操作系统沙箱。所选应用中的按钮和快捷键可能触发网络请求、修改文件或打开其他窗口。禁止提供 Shell 函数也不能阻止 GUI 内的所有命令执行路径。
- 逐步批准需要用户理解操作效果；程序尚未实现可靠的“支付 / 发送 / 删除”等语义分类。
- 屏幕与网页可能含有提示注入。模型提示词将它们定义为不可信数据，后端限制动作类型并要求批准，但不能保证模型不会被误导。
- 焦点或界面可能在检查与系统输入之间变化。任务运行中请避免同时操作目标应用；发现界面变化时停止并重新观察。
- 已发出的系统事件无法撤回。停止后不会接受新的批准或继续任务步骤，但在途调用可能需要等待其超时。
- 本机管理员或同一用户下的恶意程序可能读取进程内存、配置或浏览器会话。连接口令不是针对本机恶意软件的隔离机制。

## 文件与发布

`.env`、`.local/`、Python 缓存和原生构建缓存都被 Git 忽略。本项目只应发布源代码、示例配置、文档和不含真实用户数据的演示截图。审计日志位于 `.local/audit.jsonl`，默认以 `0600` 权限新建；关闭服务后可按需删除，或使用 `--no-audit` 从一开始禁用。

不要把本服务放在反向代理后公开访问，也不要分享带口令的启动链接。需要远程访问、无人值守操作、统一权限或组织级审计时，应先补充相应设计。
