# 开发路线

## v0.1 已实现

- [x] 本机中文控制界面和单窗口任务
- [x] 原生窗口列表、AX 树、ScreenCaptureKit 截图
- [x] 点击、双击、文本输入、控件赋值、按键、垂直滚动
- [x] Responses API 自定义函数工具
- [x] 逐步批准、拒绝、停止、时间与步数限制
- [x] 不需要密钥和系统权限的离线演示
- [x] 自动化测试、原生冒烟脚本、公开文档

## 优先完成

- [ ] 授予权限后的真实桌面和真实模型联合验收
- [ ] Retina、多显示器、中文输入与常见应用兼容性测试
- [ ] 将 helper 打包为稳定身份、可签名的 macOS 应用，改善权限体验
- [ ] 附带独立的原生测试应用，使输入、焦点与窗口边界测试可重复
- [ ] 流式模型输出、请求用量和费用显示
- [ ] 改善过期观察后的手动恢复，不要求重启整个任务

## 后续方向

- [ ] 经用户明确批准的跨窗口目标切换
- [ ] 浏览器 DOM 适配器和原生辅助功能共用规划接口
- [ ] 拖拽、水平滚动、更丰富的可验证控件动作
- [ ] 窗口内容脱敏与可配置应用 / 动作限制
- [ ] 经验证的本地多模态模型适配器
- [ ] MCP 接口，让其他代理复用观察与操作能力

清单是后续方向，不代表当前版本已具备这些能力。扩展动作前，应保留目标绑定、观察有效期和停止行为的验证。
